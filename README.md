# ReportStaff

ReportStaff is a Paper/Folia-friendly reporting plugin for Minecraft servers.

## Features
- Report system with categories
- Staff overview GUI
- SQLite / MySQL support
- HikariCP connection pooling
- Asynchronous database writes
- Java 21 support

## Build
```bash
./gradlew build
```

## Commands
- `/report <player>`
- `/reports`
- `/rsreload`
